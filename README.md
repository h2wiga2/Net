## ✨ ویژگی‌های اصلی

### 🚀 تست سرعت اینترنت
- **تست پینگ (Latency)** با اندازه‌گیری دقیق Jitter
- **سرعت دانلود** با نمایش بصری روی گیج دایره‌ای
- **سرعت آپلود** با محاسبه مصرف داده
- استفاده از **Cloudflare Edge** برای دقت بالا
- **انیمیشن‌های روان** و تجربه کاربری عالی

### 🔒 بررسی حریم خصوصی
- **شناسایی IP عمومی** با موقعیت جغرافیایی
- **تست نشت DNS** با نمایش Resolverها
- **بررسی نشت WebRTC** برای شناسایی IP واقعی
- نمایش ارائه‌دهنده اینترنت (ISP)
- هشدارهای امنیتی هوشمند

### 🌍 جستجوگر اطلاعات هاست (Host Lookup)
- **کشف کامل هاست** هر دامنه با یک کلیک
- نمایش **پرچم کشور** با emoji
- **کپی IP** با یک کلیک
- **مشاهده موقعیت در نقشه** Google Maps
- **زمان پاسخگویی** سرور
- **SSL Badge** برای سایت‌های امن
- **اشتراک‌گذاری نتایج** به صورت متنی

### 💎 معرفی سرویس ویژه
- نمایش پلن ۱۰۰ گیگ با اعتبار یک‌ساله و لینک سابسکریپشن
- معرفی ویژگی‌ها، کاربردها، شرایط سرویس و مشاهده ریز مصرف
- دکمه مستقیم خرید و دریافت پشتیبانی از طریق تلگرام
- توضیح شفاف محدودیت‌های شرایط اختلال و ریسک استفاده برای ترید

### 🎨 طراحی و انیمیشن
- رابط کاربری **مدرن و تاریک**
- **انیمیشن‌های روان** و جذاب
- **Confetti Effect** هنگام موفقیت
- **Particle Effects** در پس‌زمینه
- **Loading States** زیبا و تعاملی
- **Responsive Design** کامل برای موبایل
- پشتیبانی کامل از **RTL** (فارسی)

## 🚀 نحوه استفاده

### 1️⃣ دانلود پروژه
```bash
git clone https://github.com/yourusername/wiganet.git
cd wiganet
```

### 2️⃣ اجرای پروژه
فقط کافیه فایل `index.html` رو در مرورگر باز کنید!

```bash
# با Python:
python -m http.server 8000

# با Node.js:
npx serve

# یا مستقیم:
# دابل کلیک روی index.html
```

### 3️⃣ مشاهده در مرورگر
```
http://localhost:8000
```
